# For Glory — downloads

Arquivos para instalar o app **For Glory**. O jeito mais fácil é pelo site:
**https://forglory.online/download**

| Arquivo | Para quem |
|---|---|
| `ForGlory-android.apk` | A maioria dos celulares Android (64 bits) |
| `ForGlory-android-32bits.apk` | Celulares Android antigos (32 bits) |

- Versão **2.1.0** · Android 7.0 ou mais novo.
- Quem já tem a versão 2.0 pode instalar por cima (não precisa desinstalar). Se você tinha o app antigo (anterior à 2.0), desinstale-o antes.
- Na instalação, o Android pode pedir para permitir apps desta fonte.
- Para conferir os arquivos: `SHA256SUMS.txt`.

Este repositório guarda só os arquivos de instalação. O código do For Glory fica em um repositório privado.
