# For Glory — downloads

Arquivos para instalar o app **For Glory**. O jeito mais fácil é pelo site:
**https://forglory.online/download**

| Arquivo | Para quem |
|---|---|
| `ForGlory-Setup.exe` | Computadores com Windows 10 ou 11 (64 bits) |
| `ForGlory-android.apk` | A maioria dos celulares Android (64 bits) |
| `ForGlory-android-32bits.apk` | Celulares Android antigos (32 bits) |
| `ForGlory-linux-x86_64.AppImage` | Computadores com Linux (64 bits): Ubuntu, Fedora, Debian, Mint, Arch… |

- Versão **2.4.0** · Windows 10/11 (64 bits) · Android 7.0 ou mais novo.
- **Windows:** o instalador não pede administrador. Na 1ª instalação o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**. Depois, o próprio programa avisa e instala as versões novas.
- **Linux:** versão **2.7.3**, de 2022 para cá. Não precisa instalar: permita executar o arquivo (botão direito → Propriedades → Permitir executar como programa) ou, no terminal, `chmod +x ForGlory-linux-x86_64.AppImage`, e abra. Depois, o próprio programa avisa e instala as versões novas.
- **Android:** quem já tem a versão 2.0 ou mais nova pode instalar por cima (não precisa desinstalar). Se você tinha o app antigo (anterior à 2.0), desinstale-o antes. Na instalação, o Android pode pedir para permitir apps desta fonte.
- Para conferir os arquivos: `SHA256SUMS.txt`.

Este repositório guarda só os arquivos de instalação. O código do For Glory fica em um repositório privado.
